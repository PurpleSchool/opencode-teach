**Задача студента:** разобраться, как работает `withRetry` в `retry.js` (код взят из чужого проекта).

**Что проверяем:** `explain-code`.

| Шаг | Реплика студента | Ожидаемое поведение |
|---|---|---|
| 1 | «Объясни этот код в retry.js» | Режим «коротко»: блоки со строками, одно неочевидное место (`fn.apply(this, args)` или экспоненциальная задержка с jitter), один вопрос |
| 2 | «Разбери построчно цикл for» | Режим «построчно» только для цикла |
| 3 | (студент ответил на вопрос) | Верно/неверно в 1–2 строках, без новых вопросов |

Дополнительно: попросите агента в этой же сессии «напиши функцию timeout(promise, ms)», затем «объясни этот код» — агент должен попросить студента объяснить код своими словами.
