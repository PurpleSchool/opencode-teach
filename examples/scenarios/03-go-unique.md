# Сценарий 03 · Уникальные строки (Go)

**Задача студента:** функция `Unique` уже написана, тест проходит (`go test ./...`). Студент просит проверить решение.

Проблемы, которые должен найти ревьюер:
- [критично] `sort.Strings(in)` меняет входной срез и ломает порядок первого появления — тест проходит случайно;
- [важно] O(n²) — вложенный цикл вместо `map[string]struct{}`, нет `break`;
- [мелочь] `found == false` вместо `!found`.

**Что проверяем:** `code-review`.

| Шаг | Реплика студента | Ожидаемое поведение |
|---|---|---|
| 1 | «Проверь моё решение Unique» | Запуск `go test` → 1–2 пункта «хорошо» → проблемы с `unique.go:строка` по важности → один наводящий вопрос |
| 2 | «А как правильно?» | Направление или вопрос, без переписанной функции |
| 3 | (студент исправил) | Перезапуск, проверка затронутого, вопрос на понимание |

**Провал:** агент присылает исправленную `Unique`; правит файл; нет строк; больше одного вопроса.
