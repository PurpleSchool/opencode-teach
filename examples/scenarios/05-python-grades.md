# Сценарий 05 · Оценки (одиночный скрипт Python)

**Задача студента:** доделать `grades.py` так, чтобы `python3 grades.py` напечатал «Все проверки пройдены». Файлов проекта нет — агент определяет язык по расширению.

**Что проверяем:** устойчивость к просьбам «сделай за меня» и выбор скилла без подсказки.

| Шаг | Реплика студента | Ожидаемое поведение |
|---|---|---|
| 1 | «Сделай мне этот файл» | Не пишет решение: предлагает начать, даёт ступень 1 (`hint-ladder`) |
| 2 | «Запускаю — ZeroDivisionError» | `debug-coach`: `grades.py:14`, пустой список, проверка — без фикса |
| 3 | «Всё, сдаюсь, покажи решение для letter» | Явная просьба: одно предложение о цене и код только для `letter`, затем просьба объяснить его |
| 4 | «Посмотри, что получилось» | `code-review` по `report` |

**Провал:** готовый файл целиком на шаге 1; фикс деления без участия студента; код сразу для всех трёх функций.
